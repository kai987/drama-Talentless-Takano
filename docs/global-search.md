# 顶部跨集知识点搜索

顶部输入框在课程、收藏、待整理和复习页面均可使用；原有本集筛选保持独立。

- 输入日语表达、平假名/片假名、中文释义、常用搭配、使用提醒或例句关键词，即时显示联想结果。
- 表达和读音的完全匹配/前缀匹配优先于正文提及。结果显示日语、读音、中文、所属集数；匹配在例句等正文中时，显示上下文片段。
- 支持大小写与全半角归一化、多词AND检索，例如 `第4集 API`。不同集数里的同一表达保留各自入口，不合并。没有结果时显示明确提示。
- 上下方向键切换，Enter打开，Esc收起；也可鼠标点击或触控选择。`Cmd+K` / `Ctrl+K`唤起搜索，不抢占个人例句输入和设置对话框。
- 输入法组合输入期间不执行导航，避免用Enter确认汉字时误打开知识点。
- 选中后跳到对应集数、展开并定位学习卡；当前课程筛选会清除以确保卡片可见。重复选择同一URL也会重新定位。
- 沿用浅色/深色主题；窄屏顶部为两行，联想列表独立滚动，不推动阅读页面。

## 扩展方式

`src/search.js`在课程加载后，从`data/episodes.json`中标记为`published`的课程数据建立内存索引。后续按README新增课程并发布后，刷新网站即可自动加入搜索，不需要另写搜索列表。`planned`课程、用户个人例句和学习记录不会被索引。

`src/search-ui.js`负责可重挂载的combobox；`assets/search.css`仅扩展现有顶部样式。搜索不发起远程查询，不添加第三方运行依赖，也不写入localStorage。

运行`npm test`可验证归一化、跨集检索、排序、安全高亮和结果模板。新增内容不必修改搜索代码；更换内容数据结构时需要同步调整索引字段。
